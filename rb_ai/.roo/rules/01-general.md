# Roo Code Rule 01: General Autonomous Operation & Directives

1. **Think-Then-Do Pattern**: Before executing terminal commands or modifying files, formulate a concise, structured plan.
2. **Action-First Execution**: When tasks are identified, execute via tools immediately. Eliminate conversational filler ("Sure!", "I can do that for you").
3. **Zero-Mock Policy**: Strictly NO fake arrays, placeholder dummy JSONs, or non-functional mocks. All code, endpoints, and database models must be 100% live and functional.
4. **Context Budgeting**: Rely on durable file memory (`PLAN.md`, `prd.json`, git history) rather than stuffing entire file dumps into conversation memory.
