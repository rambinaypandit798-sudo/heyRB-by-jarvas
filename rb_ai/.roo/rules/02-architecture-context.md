# Roo Code Rule 02: Strict Context Memory & Architecture Preservation

1. **Strict Context Memory**:
   - Always read the project layout, repository dependencies, and existing architectural rules from the root structure before editing or creating any file.
   - Respect established specialist identities (e.g. in `src/lib/agents.ts`), route structures, and database schemas.

2. **Preservation of Lovable UI & Components**:
   - Keep all original Lovable UI designs, styling tokens, sticky input bar layouts, and component structures **100% intact**.
   - Do NOT rewrite or dismantle existing frontend styles, responsive dialogs, Arc Reactor HUD, floating navigation bars, or chat history renders.
   - When introducing enhancements, extend existing UI components cleanly rather than replacing them.
